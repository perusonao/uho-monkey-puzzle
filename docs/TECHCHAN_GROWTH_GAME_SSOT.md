# てっちゃん育成ゲーム SSOT

Status: Product direction v0.2
Date: 2026-09-12

## 1. Character identity

- 本名: **テナガサルオ**
- 呼び名: **てっちゃん**
- キャラクター: 茶色いオランウータンのぬいぐるみ
- 外見の基準: 大きな丸い目、明るいベージュの口元、黒白ボーダーの長袖、青いオーバーオール
- 話し方: 普通の自然な日本語。猿を強調する「ウホ」「ウホウホ」等を語尾・口癖として使用しない

## 2. Product vision

プレイヤーが「テナガサルオ（てっちゃん）」と同じ部屋で暮らし、毎日の生活を眺めたり、お世話したり、一緒に遊んだりするスマホ向け育成・生活ゲーム。

ゲームの主役はメニューや数値ではなく、**部屋の中で全身のてっちゃんが生活している姿**。

てっちゃんはプレイヤー操作を待つだけではなく、ソファに座る、歩く、寝る、ごはんを食べる、テレビを見る、本を見る、遊ぶ、プレイヤーに近寄る等の自発行動を行う。

中心体験は「能力値を最大化すること」ではなく、てっちゃんの生活・反応・性格・部屋が少しずつ変わり、また会いに来たくなること。

## 3. Room HOME

HOME画面そのものを「てっちゃんの部屋」にする。スマホ縦1画面を基本とする。

初期家具:
- ソファ
- テーブル
- ベッド
- テレビ
- 本棚
- クローゼット
- おもちゃ置き場

家具は背景装飾ではなく行動スポットとして扱う。

例:
- おなかが減る → テーブル付近へ → 「なんか食べたいな」
- 眠い → ベッドへ → 横になる／寝る
- 暇 → おもちゃへ → 遊ぶ
- テレビに興味 → ソファへ → テレビを見る
- プレイヤーがなでる → 近くへ来る／喜ぶ

MVPでは完全な自由移動AIではなく、家具ごとの定位置を使った状態遷移から開始する。

## 4. Core loop

1. 部屋を開き、今てっちゃんが何をしているか見る
2. 表情・位置・行動・ひとことから状態を理解する
3. ごはん／なでる／遊ぶ等で関わる、または生活を眺める
4. てっちゃんが家具へ移動し、行動とリアクションを返す
5. おなか・ごきげん・げんき・なかよし・性格傾向が変化
6. 家具、服、お出かけ、思い出、新しい行動が解禁
7. 次回訪問時に違う生活場面が起きる

短時間プレイ30〜90秒でも変化があり、長く遊ぶ場合はミニゲーム・着せ替え・お出かけを利用できる。

## 5. Main parameters

- おなか: 食事で回復。空腹で食卓へ行きやすくなる
- ごきげん: 遊び・好物・会話などで変化
- げんき: 睡眠・運動・活動量に関係
- なかよし: 継続的な交流で上昇
- かしこさ: 本・勉強・体験で成長
- おしゃれ: 着せ替え・買い物で成長

数値を常時すべて表示せず、行動、表情、吹き出し、必要時のゲージで伝える。

## 6. Personality system

育て方によって複数の傾向を内部蓄積する。
- あまえんぼ: なでる／一緒に過ごす
- わんぱく: 遊ぶ／運動／ミニゲーム
- かしこい: 本／勉強／クイズ
- おしゃれ: 着せ替え／買い物
- 冒険家: お出かけ／新しい体験

固定進化ではなく、傾向の組み合わせで行動頻度・好み・セリフ・イベントを変える。

## 7. First 7 Days

### Day 1 — 一緒の生活が始まる
部屋と「てっちゃん（本名: テナガサルオ）」を紹介。ごはん／なでる／遊ぶ。

### Day 2 — 好きな食べ物
食べ物選択を解禁。好物の反応差。

### Day 3 — 遊び
おもちゃ／ミニゲームを解禁。

### Day 4 — 着せ替え
クローゼットを解禁。服を追加。

### Day 5 — 本棚
本／クイズ／学び行動を解禁。

### Day 6 — 外の世界
お出かけを解禁。思い出を獲得。

### Day 7 — てっちゃんらしさ
7日間の生活から性格傾向を判定し、専用行動・セリフ・記念アイテムを解禁。

## 8. Screen structure

### Room HOME — 最重要
全身のてっちゃんと部屋を大きく表示。UIは生活空間を邪魔しない下部メニュー／必要時の吹き出し中心。

### Food
食べ物を選択。選択後はHOMEのテーブルで食事演出。

### Play
部屋のおもちゃ、またはミニゲームを選択。

### Closet
服を選択。選択後は全身モデルへ反映。

### Outing
場所を選択し、短いイベント・思い出を獲得。

### Diary
日付、出来事、写真／思い出、性格変化を振り返る。

## 9. Character asset strategy

顔だけではなく**全身素材**を標準とする。

必要な初期ポーズ:
1. 正面で立つ
2. 座る
3. 歩く
4. 食べる
5. 寝る
6. 遊ぶ
7. 喜ぶ

元写真の外見をキャラクター基準にし、ポーズ間で顔、毛色、服装、体格が別キャラクターに見えないよう統一する。

MVPでは静止画＋CSS移動／切替で生活感を作り、その後スプライト／アニメーションへ拡張する。

## 10. Save data

localStorageから開始。
- schemaVersion
- day / lastPlayedDate
- hunger / mood / energy / friendship
- intelligence / fashion
- personality tendencies
- currentRoomSpot
- currentActivity
- ownedFoods / ownedClothes / ownedFurniture
- unlockedPlaces
- memories
- miniGameBestScores

遊べなかった日への強いペナルティは設けない。

## 11. Existing puzzle treatment

旧落下パズルとモンキーコンボは削除せず、将来「遊ぶ」から起動するミニゲーム候補として保持する。

ただし旧タイトル／演出にある「ウホ」「ウホウホ」は、育成ゲームへ統合する際には使用しない。ミニゲーム名称も世界観に合わせて再設計する。

## 12. Implementation phases

### Phase 1A — completed prototype
`tecchan.html` の初期ボタン型HOME。育成データ保存の技術検証として保持。

### Phase 1B — current priority: Room-life HOME v2
- 部屋をHOME全面にする
- 全身てっちゃん表示領域
- 家具スポット
- 立つ／座る／食卓／ベッド等の位置遷移
- 自然な日本語セリフ
- ごはん／なでる／遊ぶを部屋内行動へ接続
- おなか／ごきげん／げんき
- localStorage保存
- スマホ縦1画面

完成条件: HOMEを開いた瞬間に「てっちゃんが部屋で暮らしている」と理解でき、3種類のお世話によって位置・行動・セリフが変わる。

### Phase 2 — First 7 Days
日付進行、Day 2〜7解禁、性格傾向、7日目イベント。

### Phase 3 — Living collection
着せ替え、家具追加、お出かけ、日記／思い出。

### Phase 4 — Mini games
既存パズルを世界観に合わせて再設計し、「遊ぶ」へ統合。

## 13. Current priority

**最優先は Phase 1B「全身のテナガサルオが部屋で生活するHOME v2」。**

パズル単体の追加改修より、部屋・全身キャラクター・生活行動の成立を優先する。

## 14. Success criteria

初見ユーザーが説明なしで以下を感じられること。
- このキャラクターは「てっちゃん」ことテナガサルオ
- てっちゃんがこの部屋で暮らしている
- 自分がいなくても生活していそうに見える
- 関わると行動と反応が変わる
- もっと部屋や行動を増やしたくなる
- 次回もてっちゃんに会いたい
