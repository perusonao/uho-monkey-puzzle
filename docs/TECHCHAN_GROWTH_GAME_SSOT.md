# てっちゃん育成ゲーム SSOT

Status: Product direction v0.1
Date: 2026-09-12

## 1. Product vision

主役はオランウータンのぬいぐるみ「てっちゃん」。
プレイヤーが毎日少しずつ会いに来て、ごはん・遊び・会話・勉強・着せ替え・お出かけを通じて、てっちゃんとの関係と性格が育っていくスマホ向けブラウザゲームにする。

中心体験は「数値を最大化すること」ではなく、育て方によっててっちゃんの反応・性格・生活が変わり、また会いたくなること。

旧「ウホッ！モンキーパズル」の落下ゲーム／モンキーコンボは削除せず、「てっちゃんと遊ぶ」ミニゲーム候補として残す。

## 2. Core loop

1. HOMEで今日のてっちゃんを見る
2. てっちゃんの状態・ひとことを確認する
3. 1〜3個の行動を選ぶ
4. 表情・セリフ・能力・性格傾向が変化する
5. アイテム／服／お出かけ／イベントが解禁される
6. 翌日また会いたくなる変化を残す

1回の短時間プレイは30〜90秒を目標。ミニゲームやお出かけでは数分遊べる。

## 3. Main parameters

- おなか: 食事で回復。空腹で反応が変化
- ごきげん: 遊び・好物・会話などで変化
- げんき: 睡眠・運動・活動量に関係
- なかよし: 継続的な交流で上昇
- かしこさ: 勉強・本・体験で成長
- おしゃれ: 服・コーデ・買い物で成長

パラメータはユーザーにすべて数値で見せず、表情・吹き出し・ゲージ・行動候補で直感的に伝える。

## 4. Personality system

育て方によって複数の性格傾向を内部蓄積する。

- あまえんぼ: なでる／好物／一緒に過ごす
- わんぱく: 遊ぶ／運動／ミニゲーム
- かしこい: 勉強／本／クイズ
- おしゃれ: 着せ替え／買い物
- 冒険家: お出かけ／新しい体験

一つに固定進化させず、上位傾向の組み合わせでセリフ・イベント・好みを変える。

## 5. First 7 days

### Day 1 出会い
- 名前「てっちゃん」と基本操作を紹介
- ごはん／なでる／遊ぶ
- 最初の反応差を体験

### Day 2 好み
- 食べ物を2〜3種類から選択
- 好物のヒントが出る

### Day 3 遊び
- 初ミニゲーム解禁
- モンキーコンボを候補として再利用

### Day 4 おしゃれ
- 着せ替え解禁
- 初期服＋新しい服1点

### Day 5 学び
- 本／クイズ／練習を解禁
- かしこさ傾向が反応に現れる

### Day 6 お出かけ
- 最初のお出かけ先を解禁
- 写真／思い出を獲得

### Day 7 成長イベント
- 7日間の行動から性格傾向を判定
- 専用セリフと記念アイテム
- 次週の目標／新しい場所を提示

## 6. MVP screens

### HOME
最重要画面。てっちゃんを大きく中央表示。
- 今日の表情／ポーズ
- 吹き出し
- おなか・ごきげんの簡易状態
- ごはん
- 遊ぶ
- なでる
- おでかけ
- きがえ

### Food
食べ物を選び、食後のリアクションを見る。

### Play
ミニゲーム選択。最初は1種類でよい。

### Closet
服を選んで着せ替える。MVPでは少数アイテム。

### Outing
場所選択と短いイベント。MVPでは1〜2か所。

### Diary
日付、思い出、性格変化、獲得アイテムを振り返る。

## 7. Character presentation

写真のてっちゃんの特徴をゲームのキャラクターアイデンティティとして維持する。
- 茶色いオランウータン
- 大きな丸い目
- 明るいベージュの口元
- 黒白ボーダーの長袖
- 青いオーバーオール

MVPでは実写写真をそのままHOME素材として利用可能。将来的には写真を基準に、喜ぶ・眠い・怒る・驚く等の表情／ポーズ素材を制作する。

## 8. Save data v1

localStorageから開始。

- schemaVersion
- day
- lastPlayedDate
- hunger
- mood
- energy
- friendship
- intelligence
- fashion
- personality tendencies
- ownedFoods
- ownedClothes
- unlockedPlaces
- memories
- miniGameBestScores

端末時計変更や連続ログイン強制による不快感を避ける。遊べなかった日への強いペナルティは設けない。

## 9. Existing puzzle treatment

現行 `index.html` / `game.js` の落下ゲームは当面維持する。
`combo-prototype.html` / `combo-board.js` のモンキーコンボも実験コンテンツとして維持する。

育成HOMEが成立した後、モンキーコンボを「遊ぶ」から起動し、結果に応じてごきげん／なかよし／ゲーム内報酬を付与する。

## 10. Implementation phases

### Phase 0 — Product foundation
- このSSOTを確定
- 既存パズルを壊さず育成ゲームを別入口で試作

### Phase 1 — HOME vertical slice
- `tecchan.html` を追加
- 写真／キャラクター表示
- 吹き出し
- おなか／ごきげん
- ごはん／なでる／遊ぶ
- localStorage保存
- 1画面スマホUI

完成条件: てっちゃんに会う→3種類のお世話→反応が変わる→再読込後も状態が残る。

### Phase 2 — First 7 Days
- 日付／Day進行
- Day 2〜7解禁
- 性格傾向
- 7日目成長イベント

### Phase 3 — Collection
- 着せ替え
- お出かけ
- 日記／思い出

### Phase 4 — Mini game integration
- モンキーコンボを「遊ぶ」に統合
- スコアから育成報酬へ変換

## 11. Current priority

最優先は Phase 1 の HOME vertical slice。
パズル単体の追加改修は、育成HOMEの初回プレイ体験を作る作業より優先しない。

PR #2 のモンキーコンボ強化は育成ゲームのミニゲーム候補として扱い、育成HOMEとの統合時に必要な仕様へ調整する。

## 12. MVP success criteria

初見ユーザーが説明書なしで以下を理解できること。

- この子が「てっちゃん」である
- 自分がお世話できる
- 行動するとてっちゃんが反応する
- 状態が変化・保存される
- 明日／次回も会う理由がある

最初の評価軸は継続率や課金ではなく、「てっちゃんに愛着が湧くか」「もう一度会いたいか」。
